# 运行与安全说明

安装入口和基本配置见 [README](../README.md)，接口字段见 [API 文档](API.md)。

## 节点执行与本地目录

插件通过已有 Komari Agent 派发任务。首次运行检查系统的 `curl` / `wget` 和 SHA-256 工具，从插件附带资源中下载对应架构的执行器，核对摘要后启动。不会通过 SSH 安装软件，不自动修改系统软件包。

节点数据位于 Agent 用户的 `${XDG_DATA_HOME:-$HOME/.local/share}/komari-webdav-backup`：

| 目录 | 内容 |
| --- | --- |
| `bin/` | 按架构和摘要缓存的执行器，保留当前版本及最近一个旧版本 |
| `work/` | 临时归档，任务结束后清理 |
| `results/` | 不含凭据的本地运行记录及运行锁；已结束记录保留 30 天、最多 500 条 |

下次运行会在持有节点锁时清理超过一天的本工具残留工作目录。执行器使用 Agent 的权限；容器内的 Agent 只能读取已挂载的路径。备份大小由节点磁盘空间、网络和 WebDAV 服务限制，不经面板转发。

节点在运行时维护结果和缓存，没有独立的后台清理进程；停止使用后不会继续产生文件。维护只处理可识别的数据，保留未结束、无法确认、损坏或仍被占用的记录，不跟随软链接。

## 文件语义与排除规则

- 归档保留去掉开头 `/` 的完整路径，避免不同来源的同名文件相互覆盖。重复及父子重叠来源会去重。
- 每个来源都必须存在。来源缺失、不可读、没有可归档条目、空间不足或上传失败会记录失败。
- 符号链接保存为链接，不跟随读取；来源父路径包含符号链接时拒绝备份，请填写实际路径。
- 保留常规 Unix 权限、修改时间和可用的属主信息。不保证 ACL、扩展属性、SELinux 标签、稀疏布局或硬链接关系。
- 目录中的设备、FIFO 和 Socket 等特殊文件跳过并报告警告；不支持将这些特殊文件直接作为来源。
- 文件读取期间缩短或不可读时失败；变大、替换或修改时间变化时报告相应警告或错误。完整文件树不具备快照一致性。

排除规则针对去掉开头 `/` 的路径。`*` 匹配单层，`?` 匹配单字符，`**` 跨目录；`[`、`]` 按普通字符处理，不支持正则、否定或 shell 展开。

```text
**/*.log
opt/app/cache/**
opt/app/tmp
```

## 调度、保留和中断

- 执行时间以 Komari 服务端本地时区为准。新任务默认暂停，测试通过后才可启用；默认每日 02:00、保留 7 天。
- 面板停机期间不启动新任务，恢复后合并补跑最近一个错过的计划。节点离线时任务排队；同一服务器串行执行。
- 每次任务默认最多运行 120 分钟，可配置为 5～1440 分钟。WebDAV 请求最多尝试 3 次；明确的认证和权限错误不重试，不支持断点续传。
- 只在本次归档无警告且上传验证完成后清理过期备份。按完成时间和任务配置处理，至少保留最近一份完整成功备份。`0` 天表示不自动清理。
- 清理验证所有权、节点、任务、运行 ID 和完成清单，并严格列举过期运行目录。仅含已知归档和清单时先删除归档，再检查并删除运行目录及清单，确认目录已不存在。清单保留至目录删除这一步，清理失败且清单仍可验证时，下次成功备份会重试。
- 目录中有未知文件、子目录、异常条目或无法确认的列举结果时停止删除并提示。基础目录、节点目录、任务目录、本次运行及旧版无清单目录不删除。运行目录供本插件独占使用，请勿在其中并发写入其他内容。
- 停用插件停止后续调度，已领取配置的进程可以继续上传；停用期间尚未领取配置的进程无法启动备份。
- 派发或回传不明确时显示「结果待确认」，占用节点及并发槽，避免重复执行。节点在线后会自动核对，也可点击「核对状态」。
- 核对只读取节点本地记录，不重新备份。进程已经消失且无完整终态记录时显示中断失败，必要时结合远端清单检查。
- 删除任务保留已有远端备份。修改公用存储配置会暂停已有定时任务，重新测试后启用。

## 面板写入与历史保留

面板仅在配置、计划游标、队列、执行阶段或最终结果变化时保存加密状态，相同阶段的重复心跳只更新内存中的联系时间。重启后在途运行进入结果核对流程；保存失败的变更保留为待保存状态，在后续调度重试。

面板在加载、执行结束和每日维护检查时，清理完成超过 30 天或超出最近 500 条的已结束记录。节点在运行时执行相同策略，终态按本地结果的更新时间计算。运行中、排队、结果待确认及持有运行锁的节点记录受到保护。错误、警告及面板通知错误合计最多保存 16 KiB UTF-8 文本，超出部分标注截断。

历史清理只影响执行记录，不删除对应远端归档；远端备份单独按任务保留天数处理。插件不自动删除 Komari 本体保存的命令、任务结果或日志。已有异常文件、未结束记录及清理权限错误可能使实际占用超过正常维护上限，并需结合提示检查。

## 通知

任务通知开关决定是否向 Komari 请求发送结果，通道和模板使用 Komari 已有设置。全局通知必须开启且通道配置有效。

成功、警告或失败结果会附带任务及服务器信息。通知发送错误单独显示，不把已经成功的备份改为失败；全局关闭时即使接口调用成功也不会对外发送消息。

## 权限与凭据

插件申请 `node`、`allowRoutes`、`allowSystemRPC`，用于受限文件操作、接口和 Komari 管理 RPC；不申请面板主机上的子进程、任意文件访问或额外监听端口权限。管理接口检查管理员身份与浏览器请求来源，节点接口使用独立短效授权，兼容私有站点模式。

WebDAV 密码不写入下发命令、任务结果或前端读取接口。执行器通过 5 分钟有效、只能领取一次的授权取得本次配置；独立的结果回报授权不能获取凭据。面板和 WebDAV 必须使用校验通过的 HTTPS；WebDAV 重定向被拒绝，不提供跳过证书校验开关。

参与备份的节点最终会取得公用 WebDAV 账号，拥有节点权限的人可访问运行中的凭据。请使用权限限定到专用备份目录的账号。归档本身没有额外加密，存储服务也应限制访问。

### 配置备份与迁移

面板长期插件数据目录为 `data/plugin-data/webdav-backup/`，实际位置以 Komari 的数据卷挂载为准。

| 文件 | 用途 |
| --- | --- |
| `master.key` | AES-256-GCM 配置加密密钥 |
| `state.enc.json` | 加密的公用配置、任务、调度状态和历史记录 |

**备份或迁移需要同时保留这两个文件。** 密钥与数据同机，不能抵抗拥有面板主机读取权限的管理员。已有状态损坏或缺失原密钥时插件停止加载，不会静默重置为新配置。

反馈问题时请移除密码、Cookie、API Key、短效授权、密钥及状态文件。示例路径和截图也应脱敏。

## 验证与故障排查

首次使用建议在测试目录完成「手动备份 → 下载归档和清单 → 校验 SHA-256 → 解压并比较内容」。上传成功不等于已经证明可恢复。

| 现象 | 检查项 |
| --- | --- |
| 定时任务没有执行 | 任务是否启用、面板时区、面板和节点在线状态 |
| 执行器未启动 | Agent 远程控制、下载和摘要工具、目录权限、CPU 架构 |
| 来源不可读 | Agent 用户权限；容器场景下来源是否挂载 |
| WebDAV HTTP 401 / 403 | 账号权限、入口地址和存储服务的访问规则 |
| 结果待确认 | 等待自动核对或点击「核对状态」，避免重复派发 |
| 通知未收到 | 任务通知开关、Komari 全局开关、通道及模板 |

自动测试与真实环境验证范围见 [验证记录](TESTING.md)。`--allow-loopback-http` 只供执行器本机回环自动测试，正式插件不设置该开关。
