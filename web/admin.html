恢复文件

  1. 在执行记录中打开备份详情，找到 WebDAV 远端位置。
  2. 使用 WebDAV 客户端下载同一运行目录中的 backup.tar.gz 和 manifest.json。
  3. 计算归档的 SHA-256，与清单中的 sha256 核对。
  4. 先查看归档内容，再解压到一个新的空目录，确认文件无误后进行恢复。
sha256sum backup.tar.gz
tar -tzf backup.tar.gz
mkdir restored
tar -xzf backup.tar.gz -C restored

归档保留去掉开头斜杠的原始路径。例如 /opt/app/config.json 会恢复到 restored/opt/app/config.json。符号链接会保留为链接，请在恢复前检查链接目标。

文件在备份期间发生变化时，记录会显示警告。正在运行的数据库请使用数据库自身的导出或快照工具。
